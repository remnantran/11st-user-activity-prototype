# 유저 활동성 강화 프로토타입

Figma `2026_Ideation` › 디자인+플로우(198:91725) 화면으로 만든 클릭형 프로토타입.

- 공개 링크: https://remnantran.github.io/11st-user-activity-prototype/
- 회색 동그라미 = 다음 화면으로 넘어가는 클릭 영역 (H 키로 표시 켜기/끄기)
- ← 키 또는 화면의 뒤로·닫기 버튼으로 이전 화면
- 링크 끝에 `#pdp`, `#order`처럼 화면 id를 붙이면 그 화면부터 시작

## Flow
- 홈(기본) → 프로필 → 홈·상단 멤버십 마이
- 홈·쿠폰 사용 전 → 추천 상품 → PDP → 멤버십쿠폰가 ▾ → 가격 펼침 → 바로 구매하기 → 주문 결제 → 쿠폰 변경하기 → 쿠폰 적용 / 결제하기 → 주문 완료
- 홈·활동성 높은 유저 → 멤버십전용 탭 → 멤버십 전용 → 검색 / 마트+ 탭 → 마트
